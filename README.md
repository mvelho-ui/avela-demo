# Avelã — A Esquilo Turbo (demo)

Demo de um jogo de plataformas ao estilo dos 16 bits: o **Reino do Bosque** (1-1 Bosque das Avelãs,
1-2 Copas do Carvalhal e 1-3 Outono no Carvalhal, com o Barão Gralha no fim). Gráficos e música feitos
por código, tudo no browser.

**Jogar:** https://mvelho-ui.github.io/avela-demo/

- **iPhone**: abrir no Safari → *Partilhar* → *Adicionar ao ecrã principal*. Abre em ecrã inteiro e funciona sem
  internet depois da primeira vez. Jogar com o telemóvel deitado.
- **Android**: abrir no Chrome → menu ⋮ → *Instalar app* (ou *Adicionar ao ecrã principal*).
- **Computador**: setas para mover, **Z** salta (Z+Z planar), **X** turbo, **C** pião, **V** atira uma bolota,
  **ESC** pausa, **M** som. Também funciona com comando.

Os ficheiros deste repositório são gerados automaticamente a partir do jogo (não editar à mão).
